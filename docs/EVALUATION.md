# SatQuery AI — Evaluation & Benchmark Framework

This document outlines the benchmark evaluation protocol, metrics, and dataset adapters for SatQuery AI.

---

## Benchmark Evaluation Policy

SatQuery AI strictly enforces a zero-fabrication evaluation policy:
1. Benchmark results must only be generated by running verified evaluation pipelines against physical, mounted test splits.
2. Hardcoded scores and un-evaluated placeholder metrics are strictly prohibited.
3. If a dataset is not mounted, the system truthfully reports `status: "not_evaluated"`.

---

## Supported Public Benchmark Adapters

The evaluation suite in `backend/app/evaluation/` supports the following public remote sensing datasets:

| Dataset | Evaluation Task | Metric | Adapter Class | Status |
| :--- | :--- | :--- | :--- | :--- |
| **RSVQA (Low Resolution)** | Single-Image Remote Sensing VQA | Overall Accuracy / Top-1 | `RSVQADatasetAdapter` | Ready for mounted split |
| **VRSBench** | Remote Sensing Visual Grounding | Mean IoU (mIoU) | `VRSBenchDatasetAdapter` | Ready for mounted split |
| **CDVQA** | Bi-Temporal Change Detection & VQA | Change F1-Score & Accuracy | `CDVQADatasetAdapter` | Ready for mounted split |
| **BigEarthNet-MM** | Multi-Modal Optical + SAR Classification | Mean Average Precision (mAP) | `BigEarthNetAdapter` | Ready for mounted split |

---

## Local Synthetic Pipeline Validation

To test algorithmic arithmetic (Intersection over Union, Normalized Cross-Correlation, bounding box overlap) without requiring multi-gigabyte dataset downloads, the platform provides a deterministic local validation suite:

* **Endpoint:** `POST /api/v1/evaluation/synthetic-validation`
* **Output:** Strictly labeled as `is_official_evaluation: false` with complete arithmetic telemetry.
