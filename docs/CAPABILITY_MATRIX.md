## 2. Status Category Definitions

* **IMPLEMENTED:** Fully built, verified with automated unit tests, and operational end-to-end.
* **PARTIALLY IMPLEMENTED:** Architecture and interfaces are active with verified baselines and pluggable adapters, but full large-checkpoint neural inference is deferred or requires GPU/external weights.
* **BASELINE:** A functional procedural or algorithmic method (spectral threshold, pixel differencing, linear composite) explicitly declared as an un-trained baseline.
* **PRETRAINED:** Uses real publicly available foundation model weights (hosted API or local checkpoint).
* **FINE-TUNED:** Trained or adapted specifically on domain remote sensing datasets with persisted checkpoint artifacts.
* **DEFERRED:** Architectural specification designed, but execution postponed to subsequent phases (e.g., massive multi-terabyte RAG or full ISRO/SAC test sets).
